# ⚡ BlitzKrieg

BlitzKrieg is a futuristic premium e-commerce web application built using **HTML, CSS, and JavaScript**.  
The project focuses on delivering a modern shopping experience with immersive UI, responsive layouts, interactive dashboards, and smooth user interactions.

Designed with a cinematic dark theme and premium red-black aesthetics, BlitzKrieg combines functionality with visually expressive frontend design.

---

# ✨ Features

## 🛍️ E-Commerce Functionalities

- Product listing system
- Wishlist management
- Add to cart functionality
- Product quantity controls
- Order placement system
- Order tracking progress
- Customer support queries
- Product reporting system
- Product reviews & ratings
- Search functionality

---

## 🎨 Modern UI/UX

- Premium futuristic dark interface
- Red-black cinematic theme
- Floating interactive cards
- Responsive layout
- Glassmorphism effects
- Animated product showcase
- Smooth hover interactions
- Toast notifications
- Mobile responsive design
